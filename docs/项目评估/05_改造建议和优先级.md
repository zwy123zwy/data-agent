## 5.3 可暂缓项（P2 — 面试后再说）

| 改造项 | 说明 | 面试中如何回应 |
|--------|------|--------------|
| 多租户权限隔离 (RBAC) | 当前无用户级隔离 | "架构预留了 agent_id 粒度的数据隔离，RBAC 是标准扩展" |
| 前端配套 | 依赖 Java 版前端 | "Python 版完全对齐 Java SSE 协议，零改动兼容" |
| OSS 文件存储 | 当前本地存储 | "配置驱动，生产切换只需改 FILE_TYPE=oss" |
| 水平扩展 | 单进程 | "SqliteSaver 可升级为 PostgresSaver 支持多实例" |
| CI/CD pipeline | 无 | "本地 195 测试全量通过；GitHub Actions 零成本集成" |
| 模型 A/B 测试 | 无 | "ModelRegistry 支持运行时模型切换，A/B 框架可基于此扩展" |
| LLM 调用缓存 | 无缓存 | "Langfuse 集成后可分析重复调用，针对性加缓存" |
| 错误信息中文化 | 英文 error | "技术错误保留英文便于调试；用户层 error 已通过 SSE 中文化" |
| Prompt 缓存 | 无 | "相同 prompt hash 可加 Redis/内存 TTL 缓存，降低 API 成本" |
| 数据脱敏 | 无 | "SQL 结果可在 report 节点前加脱敏层" |
