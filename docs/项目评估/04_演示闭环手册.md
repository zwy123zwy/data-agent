## 4.2 演示脚本

### Step 1: 创建 Agent + 绑定数据源

```
POST /api/agent/create
{
  "name": "销售分析助手",
  "description": "自动分析销售数据、生成趋势图表和报告"
}
→ 获得 agentId

POST /api/agent-datasource/bind
{
  "agent_id": <agentId>,
  "datasource_id": <dsId>,
  "select_tables": ["orders", "products", "users"],
  "is_active": 1
}
```

### Step 2: 简单查询演示（1 分钟）

```
GET /api/stream/search?agentId=3&query=查询本月订单总金额

SSE 流式输出（节点逐步展示）:
  data: IntentRecognitionNode → "正在识别意图..."
  data: EvidenceRecallNode → "正在召回相关知识..."
  data: SchemaRecallNode → "正在读取数据结构..."
  data: PlannerNode → "计划: 1个SQL步骤"
  data: SqlGenerateNode → "SELECT SUM(amount) FROM orders WHERE..."
  data: SqlExecuteNode → RESULT_SET (表格数据)
  data: ReportGeneratorNode → HTML 报告 + 图表
  event: complete
```

### Step 3: 趋势分析演示（2 分钟）

```
GET /api/stream/search?agentId=3&query=分析近三个月的销售趋势并生成图表

SSE 流式输出:
  ... (前置节点)
  data: SqlGenerateNode → SQL 查询按月汇总
  data: SqlExecuteNode → RESULT_SET
  data: PythonGenerateNode → 生成 matplotlib 趋势图代码
  data: PythonExecuteNode → "Python 代码执行成功"
  data: PythonAnalyzeNode → "趋势: 销售额逐月增长 15%"
  data: ReportGeneratorNode → HTML + ECharts 折线图
  event: complete
```

**讲解点**：SQL→Python 工具链闭环；PlanExecutor 循环调度；Docker 沙箱安全执行。

### Step 4: HumanFeedback 演示（1 分钟）

```
# 第一次请求 — 开启人工审批
GET /api/stream/search?agentId=3&query=分析各品类销售情况&humanFeedback=true

SSE 流式输出:
  data: PlannerNode → 展示执行计划
  data: HumanFeedbackNode → {"type":"human_feedback","plan":{...}}
  event: paused                    ← 前端暂停，显示审批组件

# 用户点击「批准」
GET /api/stream/search?agentId=3&threadId=<tid>&query=分析各品类销售情况
  &humanFeedback=true&humanFeedbackContent=同意执行

→ 继续执行: SQL → Python → Report → complete

# 用户点击「拒绝」— 重新规划
GET /api/stream/search?agentId=3&threadId=<tid>&query=分析各品类销售情况
  &humanFeedback=true&humanFeedbackContent=需要加入时间维度&rejectedPlan=true

→ 重新进入 Planner → 生成新计划 → 再次 event: paused
```

**讲解点**：LangGraph interrupt() 机制；Command(resume=...) 恢复；SqliteSaver 持久化状态。

## 4.4 故障应对

| 问题 | 应对方案 |
|------|---------|
| LLM API 不可用 | 切换 API Key 或 provider；展示架构图和技术设计 |
| MySQL 连接失败 | 提前确认 MySQL 服务运行；准备 SQLite 降级方案 |
| Docker 未安装 | Python Execute 默认使用 LocalExecutor；展示代码即可 |
| 前端无法启动 | Python 后端可独立演示（curl + Swagger UI） |
| 演示超时 | 优先展示架构 → 代码 → 最简查询；跳过趋势分析 |
