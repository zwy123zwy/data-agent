标题: 月度GMV趋势查询
类型: QA
问题: 如何查询每月销售额GMV趋势

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
回答内容:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

查询月度GMV需要 JOIN fact_orders 和 dim_date，按年月分组对 actual_amount 求和。
关键点: 必须过滤掉已取消(cancelled)和已退款(refunded)的订单，只统计有效订单。

基础 SQL:
SELECT d.year, d.month, SUM(f.actual_amount) AS gmv
FROM fact_orders f
JOIN dim_date d ON f.order_date_id = d.id
WHERE f.order_status NOT IN ('cancelled', 'refunded')
GROUP BY d.year, d.month
ORDER BY d.year, d.month

附带订单数:
SELECT d.year, d.month, SUM(f.actual_amount) AS gmv, COUNT(DISTINCT f.id) AS order_count
FROM fact_orders f
JOIN dim_date d ON f.order_date_id = d.id
WHERE f.order_status NOT IN ('cancelled', 'refunded')
GROUP BY d.year, d.month
ORDER BY d.year, d.month

按地域拆分GMV:
SELECT d.year, d.month, f.shipping_province, SUM(f.actual_amount) AS gmv
FROM fact_orders f
JOIN dim_date d ON f.order_date_id = d.id
WHERE f.order_status NOT IN ('cancelled', 'refunded')
GROUP BY d.year, d.month, f.shipping_province
ORDER BY d.year, d.month, gmv DESC

环比增长率(使用LAG窗口函数):
WITH monthly AS (
  SELECT d.year, d.month, SUM(f.actual_amount) AS gmv
  FROM fact_orders f
  JOIN dim_date d ON f.order_date_id = d.id
  WHERE f.order_status NOT IN ('cancelled', 'refunded')
  GROUP BY d.year, d.month
)
SELECT *, ROUND((gmv - LAG(gmv) OVER w) / LAG(gmv) OVER w * 100, 2) AS mom_pct
FROM monthly
WINDOW w AS (ORDER BY year, month)

同比增长率:
SELECT a.year, a.month, a.gmv, ROUND((a.gmv - b.gmv) / b.gmv * 100, 2) AS yoy_pct
FROM monthly_gmv a LEFT JOIN monthly_gmv b ON a.month = b.month AND a.year = b.year + 1
